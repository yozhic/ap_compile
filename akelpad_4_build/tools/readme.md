### Необходимые утилиты

Либо скачиваем самостоятельно по отдельности:  

|              |               |
|:------------ |:------------- |
| `jrepl.bat`  | Home page: [github.com/DaveBenham](https://github.com/DaveBenham/Windows-Batch-Scripts/blob/main/JREPL.BAT) |
| `cecho.exe`  | Home page: [www.codeproject.com](https://www.codeproject.com/Articles/17033/Add-Colors-to-Batch-Files) |
| `cmdmax.exe` (необязательно) | Home page: [github.com/tenox7](https://github.com/tenox7/cmdmax) |

Либо распаковываем весь набор из архива:  

- [для 64-битного окружения](./x64.b64)
- [для 32-битного окружения](./x86.b64)

Окончательное расположение файлов должно быть следующим:  

```
akelpad_4\
  ├─ extras\
  ├─ src\
  └─ tools\
       ├─ cecho.exe
       ├─ cmdmax.exe (необязательно)
       ├─ jrepl.bat
       └─ ...
```
